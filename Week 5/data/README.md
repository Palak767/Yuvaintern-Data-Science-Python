# Dataset

This project uses the World Happiness Report Figure 2.1 dataset.

Expected filename:

WHR26_Data_Figure_2.1.xlsx

The dataset contains information related to life evaluation and several explanatory factors.

Important variables include:

- Life evaluation
- Social support
- GDP per capita
- Healthy life expectancy
- Freedom
- Generosity
- Perceptions of corruption

If redistribution of the original dataset is not permitted, the dataset should not be uploaded to GitHub. It should instead be obtained from the original public source before running the notebook.
