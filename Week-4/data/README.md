# Dataset

This folder contains the dataset used for the Week 4 machine learning analysis.

## Dataset

World Happiness Report – Figure 2.1 Dataset

Expected filename:

WHR26_Data_Figure_2.1.xlsx

## Variables Used

- Life evaluation (3-year average)
- Social support
- Log GDP per capita
- Healthy life expectancy
- Freedom to make life choices
- Generosity
- Perceptions of corruption

The dataset is used to develop a classification model for predicting high and low life-evaluation categories.

If redistribution of the original dataset is not permitted, the Excel file should not be uploaded to GitHub. Instead, it can be downloaded from its original public source before running the notebook.
